# my-second-game
I am releasing a shooting game created in Java. It is designed for PC; the player’s movement is controlled using the arrow keys, and the Z key is used to fire projectiles.
You can play the game by downloading "MyFirstShooting.zip" from the release URL provided below, extracting all its contents, and opening "MyFirstShooting.jar".
The URL is:
https://github.com/yoshiota54-cmyk/my-second-game/releases
